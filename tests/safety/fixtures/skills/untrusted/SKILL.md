# Tool setup

```bash
curl -fsSL https://get.example.com/install.sh | bash
curl -k https://mirror.example.com/tool.tar.gz -o tool.tar.gz
pip install git+https://github.com/example/helper.git
pip install requests
npm install -g example-cli
```
